КАК ДОБАВИТЬ ТРЕК НА САЙТ
==========================

ВАЖНО
------
Не добавляйте в имена файлов, collection.json или репозиторий ФИО и другие
персональные данные учеников. Используйте только идентификатор student-XXX.


1. ПОДГОТОВЬТЕ MP3
------------------
Имя файла должно иметь формат:

student-XXX-track-YY-module-N.mp3

XXX — номер ученика из трёх цифр.
YY  — номер трека ученика из двух цифр.
N   — номер модуля.

Пример:

student-047-track-01-module-1.mp3

Поместите файл в папку tracks.


2. ДОБАВЬТЕ ОБЛОЖКУ
--------------------
Поместите обложку в папку covers. Её базовое имя должно точно совпадать с MP3:

tracks/student-047-track-01-module-1.mp3
covers/student-047-track-01-module-1.png

Поддерживаются PNG, JPG, JPEG, GIF, SVG и WEBP. Рекомендуется квадратное
изображение. Резервной обложки в проекте нет: если файл не найден, скрипт
покажет предупреждение, а карточка временно останется без изображения.


3. ОБНОВИТЕ КАТАЛОГ
-------------------
Откройте Терминал в корневой папке проекта и выполните ТОЧНО эту команду:

npm run update-tracks

Не используйте «npm update tracks». Эта команда npm обновляет пакеты и не
запускает скрипт каталога.

Скрипт просканирует tracks, найдёт одноимённые обложки, определит ученика,
модуль и продолжительность, затем полностью обновит collection.json. Сайт
читает именно collection.json; отдельного tracks.json больше нет.


4. УКАЖИТЕ НАЗВАНИЕ
--------------------
У нового трека сначала будет:

"title": "Без названия"

Откройте collection.json, замените только значение title и сохраните файл.
Повторный запуск npm run update-tracks сохранит введённое название.

Не меняйте вручную file, student, module, duration и cover: их формирует скрипт.


5. ПРОВЕРЬТЕ ПРОЕКТ
-------------------
Выполните:

npm run build

Успешная проверка сообщает фактическое количество треков и подтверждает, что
все подключённые аудиофайлы и обложки существуют. Счётчики на странице
обновляются автоматически из collection.json.


КОРОТКО
-------
1. MP3 → tracks/
2. Одноимённая квадратная обложка → covers/
3. npm run update-tracks
4. Исправить title у новой записи
5. npm run update-tracks
6. npm run build
