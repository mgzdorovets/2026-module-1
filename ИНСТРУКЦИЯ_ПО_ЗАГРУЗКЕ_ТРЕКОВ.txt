ИНСТРУКЦИЯ ПО ДОБАВЛЕНИЮ ТРЕКОВ
================================

ВАЖНО: ПЕРСОНАЛЬНЫЕ ДАННЫЕ
--------------------------
В названия файлов, папки проекта, tracks.json и репозиторий нельзя добавлять
фамилию, имя, отчество или другие данные, по которым можно определить ученика.

Для каждого ученика используется только обезличенный номер вида student-XXX,
где XXX — три цифры: student-001, student-002, student-047 и т. д.

Соответствие между реальным учеником и номером student-XXX, если оно нужно,
храните отдельно от проекта и репозитория.


1. Определите номер ученика и трека
-----------------------------------
Сначала найдите номер ученика в существующем tracks.json.

Если ученик уже есть, используйте тот же номер student-XXX и присвойте новому
треку следующий свободный номер YY:

student-032-track-01-module-2.mp3
student-032-track-02-module-3.mp3
student-032-track-03-module-4.mp3

Если это новый ученик, присвойте следующий свободный номер student-XXX,
просмотрев существующие записи в tracks.json. Первый трек получает номер 01.

Общий формат имени:

student-XXX-track-YY-module-N.mp3

XXX — трёхзначный номер ученика.
YY  — двузначный порядковый номер трека этого ученика.
N   — номер модуля: 1, 2, 3 и т. д.

Используйте только строчные латинские буквы, цифры и дефисы. Не добавляйте в
имя файла ФИО, название произведения или любые другие сведения.


2. Добавьте аудиофайл
---------------------
Поддерживается формат MP3 с расширением .mp3.

Переименуйте файл по обезличенной схеме и поместите его в папку tracks.

Пример:

tracks/student-047-track-01-module-3.mp3


3. При желании добавьте обложку
-------------------------------
Поместите обложку в папку covers. Поддерживаются форматы:

.jpeg, .gif, .jpg, .png, .svg, .webp, .tiff

Имя обложки должно полностью совпадать с именем MP3, кроме расширения:

tracks/student-047-track-01-module-3.mp3
covers/student-047-track-01-module-3.webp

В имени обложки также не должно быть ФИО или других персональных данных.

Если индивидуальной обложки нет, скрипт автоматически укажет в tracks.json:

"cover": "covers/default.jpeg"


4. Обновите tracks.json автоматически
--------------------------------------
Откройте Терминал в главной папке проекта и выполните:

npm run update-tracks

Скрипт проверит имена всех MP3 и заново сформирует tracks.json. Он автоматически:
- добавит путь к MP3;
- определит идентификатор student-XXX и номер модуля из имени файла;
- найдёт обложку с таким же именем или выберет covers/default.jpeg;
- определит размер файла;
- сохранит название у уже существующих записей.

Для нового трека, которого раньше не было в tracks.json, скрипт укажет:

"title": "Без названия"

После первого запуска откройте tracks.json, найдите новую запись и замените
название на правильное. ФИО в название добавлять нельзя.

Затем снова запустите npm run update-tracks. Введённое название сохранится, а
остальные данные будут обновлены автоматически.

Запись в tracks.json имеет следующую структуру:

Пример записи с индивидуальной обложкой:

{
  "file": "tracks/student-047-track-01-module-3.mp3",
  "student": "student-047",
  "module": "Модуль 3",
  "title": "Название трека",
  "cover": "covers/student-047-track-01-module-3.webp",
  "size": "3.5 MB"
}

Если обложки нет, используйте covers/default.jpeg.

Правила заполнения:
- file — путь к MP3 в папке tracks;
- student — тот же идентификатор student-XXX, что и в имени файла;
- module — значение вида «Модуль 1», «Модуль 2» и т. д.;
- title — название, которое будет показано на сайте; не указывайте здесь ФИО;
- cover — путь к обложке или covers/default.jpeg;
- size — размер MP3 в мегабайтах, например «3.5 MB».

Обычно вручную нужно менять только title. Не меняйте file, student, module,
cover и size: эти поля формирует скрипт.


5. Проверьте результат
----------------------
Перед публикацией убедитесь, что:
- имя MP3 точно соответствует student-XXX-track-YY-module-N.mp3;
- имя обложки совпадает с именем MP3, кроме расширения;
- file, student и cover в tracks.json совпадают с реальными файлами;
- модуль, название и размер указаны правильно;
- ни в именах файлов, ни в tracks.json нет ФИО и других персональных данных;
- tracks.json остаётся корректным JSON.


6. Опубликуйте изменения
------------------------
Загрузите на хостинг новый MP3, новую обложку (если она есть) и обновлённый
tracks.json, сохраняя папки tracks и covers.

Затем обновите страницу сайта. Если виден старый список, выполните полную
перезагрузку страницы: Cmd+Shift+R на Mac или Ctrl+Shift+R на Windows.
