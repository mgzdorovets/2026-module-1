# Музыкальная ДНК

Статический сайт: HTML, CSS, JavaScript, без новых зависимостей. Совместим с GitHub Pages и размещением в подпапке.

## Коллекция

Редактируйте `collection.json`: порядок объектов задаёт порядок карточек. Поля `student`, `title`, `cover`, `file` — подпись ученика, композиция, путь к обложке и аудио. Используйте существующие относительные пути. Текущая подборка модуля 01 содержит 11 работ и использует предоставленные обложки `cover-01.png`…`cover-11.png`. Пока настоящие имена не указаны, отображаются исходные идентификаторы учеников.

`tracks.json` — старый полный каталог. Команда `npm run update-tracks` обновляет только его; текущую подборку она не перезаписывает.

## Проверка и запуск

`npm run build` проверяет JavaScript, данные и наличие ресурсов. Компиляция не требуется: корень проекта уже готов для статического хостинга.

`python3 -m http.server 4173 --bind 127.0.0.1`

Откройте http://127.0.0.1:4173. Открытие HTML через file:// не поддерживается из-за загрузки JSON.

Один HTMLAudioElement управляет воспроизведением всех карточек. Повторное нажатие ставит трек на паузу; запуск другой карточки останавливает предыдущую. Прогресс и длительность отображаются внутри карточек, системная громкость остаётся доступна на компьютере.
