# Музыкальная ДНК

Статический музыкальный каталог без внешних библиотек. Сайт читает карточки только из `collection.json`.

## Добавление треков

1. Подготовьте публичную копию MP3 без ID3 и назовите её безопасным именем на основе никнейма.
2. Подготовьте оптимизированную публичную обложку без EXIF/XMP.
3. Добавьте карточку в `collection.json`, используя только никнейм и строку `Код ДНК: <число>`.
4. Выполните `npm run update-tracks`, чтобы проверить пути и обновить длительности.
5. Выполните `npm run build` — проверка отклонит небезопасные пути, лишние MP3 и аудио с ID3.

Полные правила и примеры находятся в `ИНСТРУКЦИЯ_ПО_ЗАГРУЗКЕ_ТРЕКОВ.txt`.

Локальная таблица соответствий, исходные файлы и скриншоты должны оставаться вне репозитория. Команда `npm update tracks` не обновляет каталог сайта: используйте именно `npm run update-tracks`.

## Проверка и локальный запуск

```sh
npm run build
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173`. Сборка проверяет JSON, JavaScript и наличие всех подключённых файлов.
