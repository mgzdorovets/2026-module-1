# Музыкальная ДНК

Статический музыкальный каталог без внешних библиотек. Сайт читает карточки только из `collection.json`.

## Добавление треков

1. Положите MP3 в `tracks/`.
2. Положите обложку с тем же базовым именем в `covers/`.
3. Выполните `npm run update-tracks`.
4. Для нового трека замените `Без названия` в `collection.json` на настоящее название и повторите команду.

Полные правила и примеры находятся в `ИНСТРУКЦИЯ_ПО_ЗАГРУЗКЕ_ТРЕКОВ.txt`.

Команда `npm update tracks` не обновляет каталог сайта: это другая команда npm. Используйте именно `npm run update-tracks`.

## Проверка и локальный запуск

```sh
npm run build
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173`. Сборка проверяет JSON, JavaScript и наличие всех подключённых файлов.
